\section{Broader Impacts}
\label{sec:impacts}

This work provides a reusable, factorially controlled methodology for
detecting gender-based bias in LLM-as-judge systems, which are increasingly
deployed in contexts with real relational stakes -- relationship-advice
products, content moderation, and HR- or mediation-adjacent tools -- where
undetected gender bias could compound existing societal asymmetries in how
men's and women's relational conduct is judged. We note two risks. First,
any specific bias findings reported here could be used to narrowly patch
model behavior on this exact evaluation format without addressing the
underlying representational bias (a Goodhart-style failure mode this
workshop's own failure taxonomy is concerned with). Second, because the
gender manipulation here is a strict binary, the released design and any
derived claims should not be read as characterizing bias against non-binary
or genderqueer identities, which this design cannot detect.
